**Fish Pond Game**

A Java-based arcade game built with **Java Swing** where the player navigates a fish through a pond while avoiding obstacles and collecting items.

**About the Game**

Fish Pond Game is a simple interactive game developed in Java using the Swing GUI framework. The player controls a fish and attempts to survive as long as possible while navigating through the pond.

The project focuses on implementing **object-oriented programming, GUI development, game logic, collision detection, and user interaction**.

**Features**

* Player-controlled fish
* Interactive pond environment
* Lilypad obstacles
* Worms and other game objects
* Collision detection
* Distance/progress tracking
* Restart functionality
* Java Swing graphical interface

**Technologies**

* **Java**
* **Java Swing**
* **Object-Oriented Programming (OOP)**
* **IntelliJ IDEA**
* **Git & GitHub**

**Main Classes**

**`Main.java`**
Starts the game and sets up the graphical interface.

**`Fish.java`**
Handles the player-controlled fish and its behavior.

**`Pond.java`**
Manages the pond environment and game elements.

**`Lilypad.java`**
Represents lilypad objects and their interactions with the player.

**`Worm.java`**
Represents collectible or interactive worm objects within the game.

##How to Run

**Requirements**

* Java Development Kit (JDK)
* IntelliJ IDEA or another Java IDE

**Running the Game**

1. Clone the repository:

```bash
git clone https://github.com/asmijn/fish-pond-game.git
```

2. Open the project in IntelliJ IDEA.

3. Make sure the Java SDK is configured.

4. Run `Main.java`.
